# Close an HDF5 object

Close an HDF5 object

## Usage

``` r
H5Oclose(h5obj)
```

## Arguments

- h5obj:

  An object of class
  [H5IdComponent](https://huber-group-embl.github.io/rhdf5/reference/H5IdComponent-class.md)
  representing an open HDF5 object.
