# Copy an existing property list to create a new property list

Copy an existing property list to create a new property list

## Usage

``` r
H5Pcopy(h5plist)
```

## Arguments

- h5plist:

  [H5IdComponent](https://huber-group-embl.github.io/rhdf5/reference/H5IdComponent-class.md)
  object representing the property list to be copied.
