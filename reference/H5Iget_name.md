# Retrieve the name of an object from a given identifier

Retrieve the name of an object from a given identifier

## Usage

``` r
H5Iget_name(h5obj)
```

## Arguments

- h5obj:

  An object of class
  [H5IdComponent](https://huber-group-embl.github.io/rhdf5/reference/H5IdComponent-class.md).
  Can represent a file, group, dataset or attribute.
