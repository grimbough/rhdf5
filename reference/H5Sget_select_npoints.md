# Find the number of elements in a dataspace selection

Find the number of elements in a dataspace selection

## Usage

``` r
H5Sget_select_npoints(h5space)
```

## Arguments

- h5space:

  [H5IdComponent](https://huber-group-embl.github.io/rhdf5/reference/H5IdComponent-class.md)
  object representing a dataspace.
